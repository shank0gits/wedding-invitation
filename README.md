# Priyank & Srashti — wedding invitation

This repository publishes the invitation to GitHub Pages from `main` using the workflow in `.github/workflows/pages.yml`.

Public site: https://shank0gits.github.io/wedding-invitation/

Edit `data.js` to update event and map details. The hotel map needs the hotel location added. The room lookup requires a separately hosted private backend configured in `guestApiUrl`; do not commit room assignments to this public repository.
